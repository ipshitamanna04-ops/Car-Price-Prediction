# Car Price Prediction System

A machine learning-based web application built with Python and Streamlit to predict car prices based on features like manufacturing year, kilometers driven, fuel type, and transmission.

## Features
* **ML Model:** Trained regression model (`car_price_prediction.pkl`)
* **Interactive UI:** Streamlit web app (`app.py`)
* **Dataset:** Processed car pricing data (`car_price_dataset_5000.csv`)
